This proposal follows our PageSpeed review of your homepage, sent separately. It lists the fixes, the scores we expect and the cost. There are two options: theme fixes only, or theme fixes plus clean-up in your apps and photos.

1

Where you are today

Desktop scores 93 for performance and 89 for accessibility. Mobile performance is the main problem.

TodayGoogle PageSpeed Insights, mobile, November 15, 2026. Performance is the only score below 90.

TodayLargest Contentful Paint is the homepage banner. It takes 7.9 s, against Google's 2.5 s "good" threshold. The other metrics are fine.

The banner image isn't large. It is slow because it shares the connection with oversized product images, an oversized footer logo, the Google Merchant badge scripts and several app scripts that all start at the same time.

2

What we'll fix

Numbers match the PageSpeed review, which has the full detail for each issue.

2.1 Theme fixes (Options 1 and 2)

#IssueWhat we'd do
1Product images load together with the bannerLoad homepage product images as the visitor scrolls
2Product images too large on mobileRequest half-screen images for the 2-column grid
3Missing in-between image sizesAdd 416 px and 600 px sizes
4Footer logo downloads at up to 1,600 pxRequest the displayed size and load it near the footer
5Extra jQuery file blocks the pageRemove it, then re-test wholesale sign-up, login and cart
6Google Merchant badge loads about 290 KB of script earlyLoad it on first scroll or tap and give its frame a title (decision in §4)
7Product card font (Sqmarket) is missingUpload the font into the theme (files needed, §4)
8Crossed-out prices hard to readRaise contrast from about 2.3:1 to about 5:1
9Banner headline coded as the smallest heading levelChange it to level 2 and keep the same look
10Desktop menu breaks the list structure for screen readersCorrect the menu markup and re-test
