2

What changes: from e-commerce catalogue to content + affiliate site

The new site is not an e-commerce store. The activity pages stay, but their job changes: they exist to show information, carry your affiliate links, and host AdSense placements — not to sell direct through a native cart.

FeatureToday (PrestaShop)New site (WooCommerce)
Cart / checkout / paymentPresent, full PrestaShop stackRemoved — not built
Add-to-cartPresent on product pagesRemoved — not built
Booking functionPresent (native)Removed — not built
Activity/product pagesSell through checkoutKept — display info, affiliate links, AdSense

If we migrate your existing product data rather than rebuild it from scratch, WooCommerce's own commerce plumbing stays underneath (that's what WooCommerce is), but we hook off the ordering/checkout path in code so it's never reachable — visitors only ever see information, affiliate links and ads. This is faster than rebuilding every activity page as plain content, and it's why we've scoped this as a WooCommerce build rather than a plain blog/CMS site.

2.1 Open question: the "top categories" block

Your homepage leads with a "most popular categories" grid — Desert Safaris, Attraction Tickets, Guided Tours, Excursions, Cruises — that we traced directly to GetYourGuide, your affiliate partner: every card in that block links out to a GetYourGuide booking URL with your partner ID attached, not to an internal PrestaShop category.

Captured directly from the live homepage — the status bar at the bottom-left shows the outbound getyourguide.com URL when hovering a card.

We need to know from you: is this block populated live from a GetYourGuide feed/API (so it updates itself), or is it a manually built, static set of links you update by hand? That decides whether we rebuild it as a live affiliate widget (ongoing sync, no manual upkeep, but depends on GetYourGuide's own widget/API) or as a static grid you edit like any other content block (simpler to build, but someone has to update it when offers change). Either is buildable — we just need to know which one before we price it into an option.
3

Three options

All three build on a free WordPress/WooCommerce theme, customised with the free theme we've referenced below as the starting point. You provide logo and brand palette colours; we don't design new layouts from scratch under any of these three — that's §3.4. They differ in how far the customisation goes and how closely the result still resembles today's activity-first layout.

3.1 Option 1 — lowest cost: free theme, light customisation (50h · $1,500)

Built for a site whose revenue comes mainly from AdSense rather than direct bookings. We install a free blog/magazine theme — reference: Ashe (WP Royal Themes) — and do the minimum custom work needed to fit your categories, activity-info layout, affiliate links and ad placements into it. The 50h is higher than a typical small theme install because of the page/section count in §1.1, not because of heavy customisation.

3.2 Option 2 — closer to today's layout (55h · $1,650)

If you'd rather the new site still read the way the current one does — activities front and centre, laid out as things a visitor books or reserves, just with a simpler, decluttered layout than today's — we lean harder on the free theme's own built-in listing/detail layouts and do proportionally less custom layout work, trading it for a small amount of extra custom code to wire up the activity-first structure.

3.3 Option 3 — free theme, more custom code (65–75h · $1,950 – $2,250)

Same starting point, with meaningfully more custom code to match a specific layout you have in mind. The range depends on exactly how far you want to go — send us the layout you're picturing and we'll land on a number inside (or, rarely, just outside) this range. For visual direction, two premium magazine themes are worth a look: Soledad — Travel and DigiQole.

Those two are paid themes — useful as a reference for the look, but Option 3 as priced still assumes a free theme underneath. If you'd rather we actually build on one of these (or another premium theme) instead of a free one, that's possible; the theme licence is billed to you separately (§5) and we'd revisit the hour estimate once we know which one. Based on what you've told us — a site built mainly to carry ads — most clients in this position choose Option 1.

3.4 Optional: design phase (+20h · +$600, on top of any option)

All three options above are theme customisation, not new design — you send logo and brand colours, we build directly on the theme. If you'd rather have an actual design pass first, that's +20h on top of whichever option you choose. Once design starts, you get three rounds of mockup revisions to review and give feedback on before we finalise anything.
